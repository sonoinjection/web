# SonoInjection Website UI Kit

## Overview
High-fidelity interactive prototype of the SonoInjection course website. Includes 4 core screens with click-through navigation.

## Screens
1. **Homepage** — Hero, featured courses, faculty highlight, stats, CTA
2. **Courses** — Filterable course listing
3. **Course Detail** — Full module, schedule, faculty, registration
4. **Faculty** — Faculty roster

## Components
- `Header` — Nav bar (light + dark variants, mobile-aware)
- `CourseCard` — Course listing card with thumb, tags, price
- `FacultyCard` — Avatar, name, title, specialty tag
- `HeroSection` — Dark navy hero with wave pattern + needle motif
- `StatsBar` — Key figures strip
- `ScheduleBlock` — Day/station breakdown
- `Footer` — Links, copyright, accreditation note

## Design Width
1280px desktop, scales responsively down to 900px.

## Usage
Open `index.html` in a browser. Click nav items and CTAs to move between screens.
